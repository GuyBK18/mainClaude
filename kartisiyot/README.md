# כרטיסיות — תוסף לכרום

## התקנה (פעם אחת)
1. לפתוח את קובץ הזיפ. נוצרת תיקייה בשם kartisiyot.
2. להעביר את התיקייה למקום קבוע, למשל תיקיית המסמכים. אם מוחקים אותה, התוסף נעלם.
3. בכרום להיכנס לכתובת chrome://extensions
4. להדליק את "מצב מפתח" (Developer mode) בפינה הימנית העליונה.
5. ללחוץ "טעינת תוסף לא ארוז" (Load unpacked) ולבחור את התיקייה kartisiyot.
6. ללחוץ על סמל הפאזל ליד שורת הכתובת ולנעוץ את "כרטיסיות".

## שימוש
- לחיצה על הסמל, או קיצור המקלדת Alt+Shift+K, פותחת את החלונית בצד.
- כל קבוצת לשוניות שפתוחה בכרום מופיעה אוטומטית תחת "פתוחות בכרום", ומתעדכנת בזמן אמת.
- קבוצה שנסגרת בכרום עוברת ל"שמורות" עם כל הפריטים, הסטטוס והמשימה.
- שם הקבוצה: לוחצים עליו ומקלידים. אפשר להשאיר ריק.
- לחיצה על פריט פותחת רק אותו. ✕ מוחק אותו מהקבוצה. ✎ משנה את הכותרת שלו.
- "צ'אט עם קלוד" ו"קלוד קוד" פותחים את אפליקציית קלוד עם רשימת הקישורים והמשימה בשורת ההקלדה. שום דבר לא נשלח עד שאתה שולח.
- בהגדרות (⚙) בוחרים אם לפתוח את קלוד באפליקציה או באתר, ותיקיית עבודה לקלוד קוד.
- גיבוי: בהגדרות, "ייצוא לקובץ". הנתונים נשמרים רק בכרום במחשב הזה.

## עדכון גרסה
מחליפים את הקבצים בתיקייה, ולוחצים על חץ הרענון של התוסף בדף chrome://extensions. הנתונים נשארים.
