# משימות לריצה על המק

הקובץ הזה נכתב לשני קוראים: לך, ולקלוד קוד כשתריץ אותו על המק.

איך מתחילים:

```
git clone https://github.com/GuyBK18/mainClaude.git   # אם הריפו עוד לא אצלך
cd mainClaude
git fetch origin claude/new-session-nlftx5
git checkout claude/new-session-nlftx5
git pull
claude
```

ואז לכתוב לקלוד: "בצע את המשימות בקובץ kartisiyot-dev/MAC-TASKS.md".

## למה דווקא על המק

את רוב הבדיקות אני מריץ בענן, בכרומיום אמיתי עם התוסף טעון: יצירת קבוצות, סגירת לשוניות, הפעלה מחדש של הדפדפן עם שחזור, ייבוא וייצוא. זה נבדק ועובד.

מה שאי אפשר לבדוק בענן:

- אפליקציית קלוד. הקישורים שמתחילים ב־claude צריכים את האפליקציה מותקנת.
- האתר של קלוד. צריך חשבון מחובר.
- החלונית עצמה וקיצור המקלדת. בענן אין סרגל כלים ואין חלונית צד אמיתית.
- הפרופיל שלך בכרום: הקבוצות האמיתיות שלך, והקבוצות השמורות של כרום עצמו.
- איך הכול נראה במסך של המק, בבהיר ובכהה.

## הוראות לקלוד שרץ על המק

1. לוודא שהענף מעודכן (`git pull`).
2. לעבור על המשימות לפי הסדר.
3. משימה שמסומנת "אוטומטי": להריץ בעצמך ולרשום את התוצאה.
4. משימה שמסומנת "ידני": להסביר למשתמש מה ללחוץ, לחכות לתשובה שלו, ולרשום אותה.
5. את התוצאות לרשום בטבלה בסוף הקובץ, ואז לעשות commit ו־push לאותו ענף. ככה הסשן בענן יקרא אותן.
6. לא לשנות קוד של התוסף בלי לשאול. אם משהו נכשל, לרשום מה קרה ואיך משחזרים.

## חלק א: עכשיו, עם הגרסה שכבר מותקנת אצלך

התשובות כאן קובעות איך אבנה כמה דברים בגרסה החדשה. הן לא עוצרות את העבודה, כי אני בונה גם גיבוי לכל מקרה.

### א1. גיבוי הנתונים (ידני, חובה)

בחלונית של התוסף: הגדרות, ואז "ייצוא". לשמור את הקובץ בתיקייה קבועה, לא בהורדות.
הגרסה החדשה ממירה את הנתונים למבנה חדש. עם הגיבוי תמיד אפשר לחזור.

### א2. אפליקציית קלוד נפתחת מקישור (אוטומטי)

```
open "claude://claude.ai/new?q=%D7%91%D7%93%D7%99%D7%A7%D7%94"
open "claude://code/new?q=%D7%91%D7%93%D7%99%D7%A7%D7%94"
```

מצופה: האפליקציה נפתחת, והמילה "בדיקה" מופיעה בשורת ההקלדה בלי להישלח. בקישור השני זה נפתח בקלוד קוד.
לשאול את המשתמש מה הוא רואה, ולרשום.

### א3. הכפתורים בחלונית (ידני)

לפתוח קבוצה בחלונית וללחוץ "צ'אט עם קלוד". אחר כך "קלוד קוד".
לרשום לכל כפתור:
- האם כרום שאל אם לפתוח את האפליקציה?
- האם האפליקציה נפתחה?
- האם הטקסט הופיע בשורת ההקלדה?

אם שום דבר לא קורה, זה המידע הכי חשוב כאן. זה אומר שצריך לפתוח את הקישור דרך הלשונית הפעילה ולא מתוך החלונית.

### א4. האתר של קלוד (ידני)

בהגדרות התוסף: "צ'אט עם קלוד נפתח", לבחור "באתר". ללחוץ שוב על "צ'אט עם קלוד".
לרשום: האם הטקסט רק ממתין בשורת ההקלדה, או שנשלח מעצמו?
אם הוא נשלח מעצמו, זה סותר את ההחלטה שלך ששום דבר לא נשלח אוטומטית.

### א5. קיצור המקלדת (ידני)

ללחוץ Option+Shift+K כשהחלונית סגורה.
לרשום: האם החלונית נפתחת? אם לא, לפתוח את chrome://extensions/shortcuts ולרשום מה מוגדר שם לכרטיסיות.

### א6. הקבוצות השמורות של כרום (ידני)

1. לבדוק אם בסרגל הסימניות יש קבוצות שמורות של כרום (רשימה של קבוצות שנסגרו).
2. בחלונית: לבחור קבוצה פתוחה וללחוץ "סגירה ושמירה".
3. באותה קבוצה בחלונית: "פתיחת הכל".
4. לבדוק ברשימת הקבוצות השמורות של כרום: האם נוצר שם עותק נוסף של הקבוצה?

## חלק ב: הגרסה החדשה (מוכנה)

### ב1. בדיקות אוטומטיות על המק (אוטומטי)
```
node --test kartisiyot-dev/tests/background.test.js
npm install --no-save playwright && npx playwright install chromium
PLAYWRIGHT=$PWD/node_modules/playwright node kartisiyot-dev/tests/e2e.js
```
מצופה: 28 בדיקות עוברות, ו־"ALL PASSED" בבדיקה בכרומיום.

### ב2. התקנה מעל הגרסה הישנה (ידני)
1. בכרום: chrome://extensions. בכרטיס של כרטיסיות, "הסרה" לא! רק להחליף תיקייה או ללחוץ על חץ הרענון אחרי git pull.
2. אם הגרסה הישנה נטענה מתיקייה אחרת: לפני הכול לייצא גיבוי (א1), אחר כך להסיר את הישנה ולטעון את התיקייה kartisiyot מהריפו, ולייבא את הגיבוי ("הוספה לקבוצות הקיימות").
3. לבדוק: כל הקבוצות, הסטטוסים והמשימות במקום.

### ב3. כפתורי קלוד (ידני)
1. בהגדרות: "בדיקת קישור". מצופה: כרום שואל אם לפתוח את קלוד, והמילה "בדיקה" מופיעה בשורת ההקלדה בלי להישלח.
2. בקבוצה פתוחה: "צ׳אט עם קלוד" ו"קלוד קוד". הטקסט כולל כותרות, קישורים, הערות ומשימה.

### ב4. סגירה ופתיחה של כרום (ידני)
1. להשאיר שתי קבוצות פתוחות, אחת עם סטטוס ומשימה. לבחור עיצוב זכוכית ומצב כהה.
2. לצאת מכרום לגמרי (Cmd+Q) ולפתוח שוב.
3. מצופה: העיצוב והמצב נשארו, כל קבוצה מופיעה פעם אחת, והסטטוס והמשימה במקום.

### ב5. התנהגות (ידני)
1. לסגור לשוניות בקבוצה אחת אחת עד הסוף: הקבוצה עוברת לסל, עם "ביטול".
2. לחיצה ימנית על קבוצה בכרום, "Ungroup": הקבוצה עוברת לסל, עם "ביטול".
3. לגרור פריט מקבוצה לקבוצה. בקבוצה פתוחה, הלשונית עוברת גם בכרום.
4. Option+Shift+K פותח את החלונית.
